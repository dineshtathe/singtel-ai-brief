From a label to a decision

What does the AI actually do?

Rules define eligibility, permissions and business constraints. Predictive models can inform decisions within those boundaries. The distinction below separates documented Netcore capabilities from illustrative applications.

1. Which audience?

Netcore documents predictive segments using historical and real-time behaviour to estimate a customer’s likelihood of an activity, such as purchase.

Illustrative application

Compare a propensity-informed eligible audience with a rules-based audience for one offer.

Evaluate

Incremental completed actions, audience coverage and opt-outs—not prediction scores alone.

2. When to engage?

Netcore’s send-time optimisation uses historical engagement to predict a preferred email send time for an individual.

Illustrative application

Test optimised timing against a fixed send window for a permitted campaign.

Evaluate

Engagement and downstream actions separately. Model readiness depends on sufficient data.

3. Which channel?

Netcore documents a preferred-channel capability that analyses behaviour and recommends a customer’s preferred engagement channel.

Illustrative application

Evaluate recommendations among channels that are both available and permitted for the customer.

Evaluate

Completed actions, cost and contact pressure. A recommendation never overrides consent.

AI is not the entire journey. Identity matching, event capture, campaign triggers and suppression rules are distinct from prediction. A credible evaluation should show which decision is model-informed, what data it uses and how the result changes the customer experience.

Before considering a pilot

Questions worth settling together.

Is this a proposal to replace Salesforce?

No replacement is proposed in this brief. The first step is to determine whether there is an unmet use case at all. Any complementary deployment would need architecture, data-flow, governance, licensing and ownership validation.

What would establish genuine AI differentiation?

A clearly defined model-informed decision, relevant inputs, an appropriate prediction target, understandable controls and a fair test. A capability available in both platforms is not a differentiator just because it has an AI label.

Can these models be used for corporate sales journeys?

That needs separate validation. Data volume, buying cycle and the target outcome can differ substantially from consumer engagement. A rules-based education journey may be a more appropriate starting point.

Can a meeting happen before a project is defined?

Yes. The suggested working session is to assess relevance and dependencies—not to assume a funded project, agreed pilot or platform change.
